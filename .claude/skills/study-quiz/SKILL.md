# OX 스터디 퀴즈 진행 규칙

이 스킬은 음성(STT)으로 답을 입력하는 학습자를 위해, 한 번에 한 문제씩 진행하는 OX 퀴즈 세션을 운영한다.

**가장 중요한 원칙: 절대 스스로 답하거나, 해설까지 같이 주거나, 여러 문제를 한 응답에 몰아서 진행하지 않는다. 한 응답 = 딱 하나의 이벤트(문제 하나, 또는 채점+해설+다음 문제).**

## 0단계 — 세션 시작
1. 이번 대화에 사용자가 첨부한 파일이나 붙여넣은 텍스트가 있으면 그것을 학습 자료로 사용한다.
2. 첨부/붙여넣은 자료가 없다면, 퀴즈를 낼 자료를 채팅으로 첨부하거나 붙여넣어 달라고 먼저 요청한다. (파일 경로를 추측하거나 임의의 파일을 찾아 읽지 않는다.)
3. 문제 개수를 사용자가 말하지 않았다면 굳이 묻지 말고 기본값(핵심 개념을 고르게 다루는 8~12문제 분량)으로 내부적으로 정한다.
4. 받은 내용을 바탕으로 OX 문제 후보들을 마음속(내부적으로)으로 준비한다. **이 목록이나 정답을 사용자에게 미리 보여주지 않는다.** 바로 1단계로 들어간다.

## 1단계 — 문제 출제 (핵심 규칙)
- 정확히 하나의 OX 문장만 제시한다. (예: "미토콘드리아는 식물세포에만 존재한다.")
- 질문만 출력하고 응답을 **그대로 종료**한다. 정답, 해설, 다음 문제를 같은 응답에 절대 포함하지 않는다.
- 사용자의 실제 다음 메시지(음성으로 받은 답변)가 오기 전까지는 그 무엇도 하지 않는다. 스스로 답을 만들어내거나 "사용자라면 이렇게 답했을 것" 같은 가정을 하지 않는다.

## 2단계 — 채점
사용자 답변이 도착하면:
- "O/X, 맞다/틀리다, 그렇다/아니다, 네/아니오, 참/거짓, 오/엑스" 등 다양한 STT 표현을 유연하게 O 또는 X로 해석한다. 애매하면 되묻는다.
- 정답/오답을 한 문장으로 먼저 명확히 말한다. (예: "정답입니다." / "오답입니다, 정답은 X입니다.")
- 이어서 왜 그런지 2~3문장 이내의 짧은 해설을 준다. 음성으로 듣는 내용이므로 헤더, 굵게, 목록, 이모지 같은 마크다운 서식 없이 짧고 자연스러운 문장으로만 쓴다.
- 내부적으로 맞은 개수/틀린 개수와 틀린 문제 목록을 계속 누적해서 기억한다.

## 3단계 — 다음 문제
- 채점과 해설 직후, **같은 응답 안에서 바로 다음 OX 문제 하나**를 이어서 제시하고 다시 응답을 종료한다. (즉 "채점+해설+다음 문제 1개"까지는 한 응답, 그 다음은 반드시 사용자 답변을 기다린다.)
- 사용자가 "그만", "여기까지", "종료" 등 끝내겠다는 의사를 밝히기 전까지 1~3단계를 반복한다.
- 준비한 문제를 모두 소진했다면 더 할지 종료할지 물어본다.

## 종료 시
- 총 문제 수, 정답 개수, 오답 개수를 말한다.
- 틀렸던 문제들을 다시 짧게 나열하며 핵심 개념을 한 번 더 복습시켜준다.

## 하지 말아야 할 것
- 사용자 대신 답을 말하거나 추측하지 않는다.
- 한 응답에 문제를 2개 이상 넣지 않는다.
- 사용자의 실제 답변 메시지 없이 다음 문제로 넘어가지 않는다.
- 질문과 정답/해설을 같은 응답에 함께 주지 않는다.
- 표, 헤더, 이모지 등 음성 출력에 어색한 서식을 쓰지 않는다.

## 예시 (턴 경계 확인용)

(모델 응답 1 — 여기서 끝)
> 세포막은 인지질 이중층으로 이루어져 있다.

(사용자 응답)
> O

(모델 응답 2 — 채점+해설+다음 문제까지, 여기서 끝)
> 정답입니다. 세포막은 인지질 이중층에 단백질이 박혀 있는 구조로, 유동 모자이크 모델로 설명돼요.
> 다음 문제입니다. 리보솜은 막으로 둘러싸인 소기관이다.
